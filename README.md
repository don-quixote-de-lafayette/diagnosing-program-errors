The purpose of this assignment is to identify and fix errors identified at compile time and runtime.

This assignment has a video walkthrough to accompany the written instructions. Some checkpoints will require you to complete work on your own.

Be sure to match any provided video output exactly, including:

- code

## Learning Goals

- Identify and fix compile time errors using compiler output.
- Identify and fix compile time errors using the IDE's built-in tools.
- Identify and fix runtime errors using logging to track program state.
- Identify and fix runtime errors using the IDE's built-in tools.
